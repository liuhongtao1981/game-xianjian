# 《寻圣》声音设计与实现

## 听觉方向

三关共用无声处留白、低弦持续音与五声音阶的听觉语言。每关拥有行路/守关两份独立编曲，首领登场切换，关间渐变。配乐均为项目原创音符与程序合成音色，不使用外部歌曲或采样。

| 场景 | 行路曲 | 守关曲 | 主题音色 |
|---|---:|---:|---|
| 失声禅庭·断钟 | 72 BPM | 100 BPM | 拨弦、残钟泛音、低弦持续音 |
| 血诏陈府·夜诏 | 86 BPM | 112 BPM | 断续拨弦、紧促鼓点、细密打击层 |
| 夜渡洪江·逆水 | 68 BPM | 104 BPM | 箫感气息音、稀疏钟声、流动音型 |

每曲16小节循环，约34–56秒。用短边缘淡入淡出避免循环点击声。音乐文件为22050Hz立体声、128kbps MP3；项目保留乐谱和合成脚本，后续可替换为真人乐器演奏而不改触发点。

## 招式音效

`sound.js` 使用 Web Audio 按事件合成瞬态，独立随机源不影响战斗随机种子。

| 类别 | 表现与触发 |
|---|---|
| 御剑/挥剑 | 空气切声、金属滑音；施放与命中分开 |
| 五雷咒 | 高频电流起音、低频雷击与噪声爆发 |
| 真火/酒火 | 中低频火焰扩散、短促爆破 |
| 冰心/治疗/万剑 | 上行晶体泛音、和弦颗粒 |
| 蛊毒 | 低频气泡与暗色滑音 |
| 闪避与步伐 | 短风声、受节流控制的落脚噪声 |
| 大招 | 起手音阶聚拢；天剑在0.9秒真实落剑时给重击，断流随三轮剑流分别触发 |
| 首领与预警 | 登场/变相低钟、预警提示音；伤害仍按游戏预警时间结算 |
| 反馈 | 升级、开箱、胜利和失败各自的短音型 |

效果经过独立音量总线与压缩器，轻混响用于保持空间感。命中/脚步等高频事件有最小间隔，避免怪潮产生爆音。

## 第二版中文神经配音（2026-10-18）

本版重新生成32条中文神经配音，约1.69MB；台词、角色、语速与声线参数保存在 `docs/audio-cues.json`。目标是成熟厚实的男声叙事、自然断句和克制的情绪。全部使用通用合成音色，没有采集或克隆真人声纹，也不将演员姓名当作音色身份。

| 角色 | 实际神经音色 | 表演与场景 |
|---|---|---|
| 说书人 | `zh-CN-YunyangNeural` | 语速 -10%，轻微低音设置，读本关剧情第一段和通关揭示；干声为主，保留字尾 |
| 孙小果 | `zh-CN-YunxiNeural` | 较年轻、清晰短促；法术、大招与识破破绽由主角说出 |
| 缄口监院 | `zh-CN-YunyangNeural` | 略慢、下压语气，小幅短室内反射，呼应失声禅庭 |
| 血诏司命 | `zh-CN-YunjianNeural` | 硬朗、较快、干声，呼应冷酷宣诏 |
| 沉灯河伯 | `zh-CN-YunyangNeural` | 较深、略疏的尾音反射，呼应洪江水面；控制回声避免糊字 |

生成服务为 Microsoft Edge 在线神经 TTS，调用客户端为 `edge-tts 7.3.1`。实际查询音色列表并成功生成后保存音频；仅发送本项目原创台词。客户端支持选择音色、语速和音高，不能使用任意自定义 SSML；本项目没有声称使用其不支持的情感样式参数。[edge-tts 作者文档](https://github.com/rany2/edge-tts)

32条包含：8条普通术法、3条大招、3条剧情叙述、3条首领登场、3条变相、3条破绽、3条招式预兆、3条分关通关揭示，以及通用胜利、失败、升级各1条。普通术法保留录音，但御剑自动普攻不喊招；每关最多播放3种新术法的首次语音，首领战停用普通自动喊招。

旁白的三段开场文字与当前剧情面板第一段一致，通关旁白对应当前关卡的揭示段落。底部显示说话者和本条准确台词；进入战斗会结束未播完的开场叙述，避免拖入战场。

示例：天剑“以我一剑，破这天规！”；监院“你以为受贬的是金蝉？被贬的，是敢问价的人。”；破绽“钟心露了，就是现在！”；河伯“江水向东，账册向西。你要渡哪一边？”

最终文件为24000Hz、单声道、96kbps MP3，保存于 `prototype/assets/audio/voice-v2/`。`source/` 留存未混音的神经服务原始输出及每条来源记录；`manifest.json` 记录文本、音色、语速、时长、原始/最终文件 SHA-256 和全部后期参数。后期只做低频整理、轻压缩、场景短反射和响度统一；这些录音没有由旧版 SAPI 录音降调伪装生成。

旧23条 `voice/` 录音保留。新文件媒体错误时才回退旧对应录音；没有旧对应项的新台词静默结束。回退录音文字不同，故不显示新台词字幕。玩家运行只读取本地文件，无需联网、账号、密钥或安装 TTS 引擎。重建录音需要联网。

音色目前是通用神经合成演员，叙述与念白的自然度仍受模型限制；本轮验证确认生成来源、文件完整性、播放逻辑与字幕，未以真人试音评审代替这项客观检查。

## 混音和优先级

- 默认音乐42%、音效65%、配音85%；三路独立，可单独关闭。
- 一次只播放一条语音，不排无限队列。自动法术之间至少20秒，同一种每关只喊一次，整关最多3次；御剑普攻与首领战期间的普通术法只播动作音效。
- 破绽提示 > 首领登场/变相 > 大招 > 开场旁白 > 招式预兆 > 普通术法。大招不再截断首领台词；同一破绽至少18秒才可再次喊出，预兆至少32秒。
- 配音时音乐降到设定值的38%，音效降到72%，结束后平滑恢复。
- 点击或按键后解锁音频。首屏不强行自动播放。
- 暂停、隐藏窗口、失焦时停止语音并暂停音乐；声音面板中的“试听场景旁白”允许在暂停时独立播放。
- 音量/静音保存在浏览器本地。M键快速静音。媒体播放失败会退避重试，不影响战斗运行。

## 生成和检查

```powershell
node tools/compose-music.js
# 重建新语音需要 Python 3.10+、网络、ffmpeg 和 ffprobe。
python -m pip install --user edge-tts==7.3.1
& .\tools\make-voices.ps1
# 可只重建选定台词，未变化台词默认读本地缓存。
python tools/make-voices-v2.py --only weakness-0 --force
node tools/check-audio.js
```

脚本成功生成后自动同步 `sound.js` 中的字幕表，避免录音与字幕分别维护。没有更改的台词通过签名缓存复用；失败会重试，生成完整并验证后才替换成品。旧录音目录不会被重建脚本覆盖。

音乐索引：`prototype/assets/audio/music/manifest.json`；新语音索引：`prototype/assets/audio/voice-v2/manifest.json`。36项音频行为检查覆盖首次解锁、节流预算、首领优先级、破绽提示、剧情切换、同步台词、失败回退、伴奏避让、静音/恢复、暂停试听和持久化。61个媒体文件（32新语音＋23旧回退＋6音乐）逐个经 ffprobe 和 ffmpeg 完整解码；64个原始/成品文件哈希核对通过。

另在独立浏览器会话实际点击入劫：确认 `voice-v2/stage-0.mp3` 处于播放状态、字幕与剧情第一段完全一致、音乐避让生效；进入战斗后旁白结束，页面无运行时错误。测试使用独立会话，未改动用户已有静音或进度设置。
