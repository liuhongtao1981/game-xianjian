# 自动续关、人物状态与长期修仙

2026-10-18 实现说明。本文件优先于旧版设计文档中“死亡恢复入关构筑”的规则。

## 自动续关

- 同一浏览器、同一来源网址使用 `xunsheng-save-v2`；等级、经验、术法、法宝、属性、护盾、剑意、技能冷却、待选升级与原选项、修仙材料、关卡进度和领取账本在一个 JSON 中提交。
- 活跃战斗每 5 秒保存；升级、材料、奖励、突破、入坛、死亡、通关、换关和返回菜单立即保存。页面隐藏、失焦、退出时补存。
- 首页优先显示“继续历程”。探索恢复位置、已净营地、当前波次及未击杀名额；未完成普通怪重新预警后以完整生命生成。巡逻不保存残血和攻击动作。
- 首领战刷新回到入坛前位置，保留人物当前成长与资源，重开完整首领战。暂停后确认继续才重新推进时间。
- 升级原选项不重新抽取；宝箱已应用的效果不重复应用；证词未确认时恢复领取面板；通关后未领取的核心材料和行粮继续保留待选状态。
- 死亡、暂停重入本关永久保留成长，补满生命并清空当前护盾；本轮已领遗箱、证词、精英和首领材料不因重试或刷新重发。
- 旧 `xunsheng-progress-v1` 保持不删除；仅迁移其中实际存在的入口构筑及通关记录。旧档没有保存的关中位置与升级无法凭空恢复。旧属性不降低，经验按进度比例迁移。
- 最近有效存档备份于 `xunsheng-save-v2-backup`。主档损坏时恢复备份。存储不可用显示“尚未保存”；突破结算写入失败时撤回本次属性和耗材。另一窗口写入更高版本后旧窗口停止写入，要求载入最新记录。
- 不提供账号、跨设备或 localhost 与 GitHub Pages 之间的自动同步。浏览器清理站点数据会移除本地存档。

三难通关、领取全部首领材料后可开启轮回重战。每轮按出征时境界固定劫阶，妖怪及首领生命额外乘 `1.22^劫阶`、攻击伤害额外乘 `1.18^劫阶`，不额外增加数量。劫阶 t 可定向选取序号 1 至 min(13,t+1) 的核心材料。首领仍须完成真实机关、诱招与破绽，标准档至少五次输出窗口。

## 突破与上限

只可在祭坛外、650 世界单位内无交战妖怪时突破。修为达标才能尝试；材料备齐为 100%，缺材成功率为 `5 + 95 × (0.7 × 核心完成比例 + 0.3 × 辅材完成比例)^3`%，显示一位小数。投入材料无论成败都消耗，失败扣所需修为的 10%，不掉境界。结果写盘成功后才反馈，必须确认结果后才能再次操作。

成功后生命和护盾基础上限乘 1.12、伤害乘 1.08；生命增加新旧生命上限差，护盾不自动补满。r 为当前境界序号：

| 属性 | 本境上限 |
|---|---|
| 生命上限 | floor(600×1.28^r) |
| 护盾上限 | floor(250×1.25^r) |
| 伤害倍率 | 8×1.22^r |
| 移速 | min(520,380+10r) |
| 暴击 | 60%+r% |
| 减伤 | 60%+0.8r% |
| 最低冷却倍率 | max(0.35,0.55−0.015r) |
| 拾取范围 | min(650,360+20r) |
| 每秒护盾回复 | 6+r |
| 经验倍率 | 3 |

升级、装备与行粮统一封顶；已满属性不进入强化池，全满时提供调息恢复卡，避免选卡死锁。术法仍五级、最多六门，法宝最多八件。前 15 级经验门槛不变；此后为第 15 级需求加 `80(L−15)+8(L−15)²`。

## 模块与验证

- `cultivation.js`：14 境界、配方、概率、材料、劫阶收益与统一属性上限。
- `run-save.js`：单包存档、备份、迁移、多窗口写入保护、安全续关及领取账本。
- `character.js` / `character.css`：人物、材料、突破与继续入口。世界和遭遇模块导入／导出不含函数、音频、动画或攻击对象。
- `node tools/check-saves.js`：24 项自动存档、续关、重复领奖、死亡保留、旧档、备份、冲突与失败检查。
- `node tools/check-cultivation.js`：22 项境界、配方、概率、失败、上限、经验与结算事务检查。
- 继续运行既有战斗、动作、首领、世界、拾取、营地与跨关回归。

本次标准主路 3 个种子的连续三关共 9 场全部通关，每关均完成两处精英；四难度、三大招、三种子的 36 组连续首领模拟共 108 场通关。大乘及仙王的声明构筑各完成三场真实首领状态机模拟，均需五次真实破绽。高境界测试使用可达到的属性上限 70% 与满级六术，测试前设置构筑，战斗中不修改生命、伤害、冷却或破绽；不代表常规玩家此时必有该构筑。

经济报告 `寻圣-修仙经济模拟.json` 对主路、全图、纯巡逻冒险分别使用三种子和固定战斗速度假设，调用实际修为、配方、概率及结算代码。主路约 49.45 小时、全图约 48.37 小时，纯巡逻缺核心材料冒险约 121.85–188.27 小时。模型不模拟导航、死亡、构筑或真人决策；这是超过 20 小时目标的经济检查，不是实际游玩时长承诺。
