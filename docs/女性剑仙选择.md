# 女性剑仙选择

出征界面新增原创女剑仙「沈听澜」，与孙小果并列选择。月白青衣、青玉发簪与独立十二帧图集，覆盖四帧奔跑、四帧挥剑、两帧待机、施法和大招。图集行边界与跨格剑尖分别测量，身体法相按各动作锚点偏移，战斗与人物面板共用绘制。

- 两位角色属性、术法、判定半径、技能时序和境界收益完全相同，角色选择为外观身份选择。
- 选择后可「继续历程」沿当前章节位置切换，或重新出征；等级、经验、装备、术法、材料和奖励记录保留。未确认出征／续关的预览选择不写入存档。
- 姓名同步出征标题、头像、人物面板、章节剧情文字和残卷。原有旁白音轨继续沿用，本次未新增女性角色专属语音。
- 存档继续使用v3，在人物构筑中增加 `heroId`。旧档缺少该字段时恢复孙小果；未知ID被校验拒绝。死亡重试、换关和刷新均保留选择。
- 续关切换与现有存档服务共同保存；保存失败恢复原身份并显示存储状态，不覆盖较新窗口的进度。
