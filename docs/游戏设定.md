# 《仙剑·回魂》游戏设定案 v0.3

> 方向修正：**控制主角的动作肉鸽**（灵画师式），不是回合制卡牌。
> 类型：单机 · 俯视角动作肉鸽 · 割草 ｜ 平台：PC 优先，移动端移植
> 单局：正式版 15–25 分钟 ｜ 原型 2.5–3 分钟
> 一句话：**走位杀妖，拾灵提卡，开箱夺宝——直到你打得过宿命。**

---

## 零、参照与定位

按你指定的参照拆成三件事：

| 参照 | 拿走什么 |
|---|---|
| **灵画师**（修仙小游戏） | 控制主角亲自下场；杀怪升级「提卡」；宝箱开出新装备/新术法 |
| 幸存者类（吸血鬼幸存者） | 自动施法、密集小怪、3–5 分钟一局的爽感 |
| 仙剑 | 五灵、御剑、酒神、女娲后人，以及「改写结局」的情感目标 |

不做：回合制、卡组管理、走格子。**主角在场上跑，术法自动打，升级时停下来选卡。**

---

## 一、核心循环

```
走位杀妖 ──掉灵气──▶ 拾取升级 ──▶ 三选一提卡 ──▶ 术法/属性变强
   ▲                                    │                    │
   │                                    ▼                    │
   └──────── 开宝箱（法宝/失传术法）◀───┴──── 杀更密的妖 ────┘
                                              │
                                        章节 Boss → 通关/梦醒
```

三层节奏缺一不可：

| 层级 | 时间尺度 | 反馈 |
|---|---|---|
| 秒级 | 每次施法 | 飞剑命中、雷光跳跃、暴击飘字、掉落吸附 |
| 分钟级 | 每 20–40 秒 | 升级三选一、宝箱开启、术法进化 |
| 局级 | 每 2–20 分钟 | Boss、通关、解锁 |

「杀怪 → 升级提卡」的间隔必须短：**前 30 秒至少升 3 级**，否则手感起不来。

---

## 二、操作与战斗

- 俯视角 2D，全屏竞技场；WASD/方向键/虚拟摇杆移动。**Esc 暂停**。
- **空格闪避**：短距离冲刺 + 0.3 秒无敌，2 秒冷却。
- **术法自动施放**：已习得的术法各自冷却，自动索敌。玩家只负责走位与拾取。
- 手动介入点：闪避、终局大招「剑意」（击杀充能，全屏清场，Q 键）。
- 五灵：术法带属性（水/火/雷/风/土），妖物有属性；克制 ×1.5、被克 ×0.75。
- 伤害显示、暴击、击退、护盾、中毒、灼烧、减速——都要有明确的视觉反馈。

**为什么自动施法**：灵画师/幸存者类的核心乐趣是「走位 + 构筑」，不是搓招；自动施法把操作门槛压到最低，手机也能玩。大招留给玩家做关键决策。

---

## 三、术法体系（首版 8 个，各 5 级）

| 术法 | 定位 | 1 级效果 | 升级方向 |
|---|---|---|---|
| 御剑术 | 基础单体 | 向最近妖物掷飞剑 | 伤害、额外飞剑、穿透 |
| 五雷咒 | 连锁 | 雷光在 2 个目标间跳跃 | 目标数、伤害、麻痹 |
| 三昧真火 | 近身 AoE | 周身业火 | 范围、伤害、灼烧 |
| 万剑诀 | 环绕 | 飞剑绕身旋转 | 剑数、转速、伤害 |
| 冰心诀 | 防御 | 获得护盾 | 护盾量、反伤、冻结 |
| 蛊毒 | 持续 | 地面毒瘴 | 范围、毒伤、传染 |
| 酒神咒 | 爆发 | 指定位置爆炸 | 范围、伤害、醉酒 |
| 观音咒 | 回复 | 回血 | 回复量、净化、护盾转化 |

设计规则：

- 每个术法有明确的「形状」（直线/连锁/环身/地面/爆发），避免同质化。
- 升级不是纯加数字：3 级、5 级各给一个质变（如御剑术 3 级变两把剑）。
- 最多带 6 个术法；槽满后只能精进，逼玩家做取舍。

---

## 四、境界与「提卡」

- 杀妖掉灵气，拾取获得经验；经验满 → 境界 +1 → **暂停，三选一**。
- 卡池三类：
  1. **新术法**（未习得，且槽位 < 6）
  2. **精进**（已习得术法 +1 级，未满 5 级）
  3. **强化**（伤害 +15%、移速 +8%、生命 +20、冷却 -8%、暴击 +6%、拾取 +30%）
- 每次升级从卡池随机 3 张，不重复；术法权重高于强化。
- 升级本身回复 8 点生命——给玩家「再撑一轮」的续航。

**节奏目标**：一局 15 分钟约 25–30 次升级；原型 3 分钟约 10–12 次。

---

## 五、宝箱与法宝

宝箱来源：

- 精英妖必掉；
- 每 55 秒场上随机刷一个；
- Boss 阶段转换时掉落。

宝箱内容二选一：

- **法宝**（永久被动，8 件）：木剑（伤害 +20%）、疾风靴（移速 +10%）、酒葫芦（生命 +30）、五毒珠（攻击附带毒）、女娲血玉（每秒回盾）、天罡战气（暴击 +10%）、聚灵珠（拾取 +40%）、护心镜（减伤 15%）。
- **失传术法**（直接习得一个未拥有的术法，35% 概率）。

法宝要「改规则」而不是纯加数值——例如五毒珠让所有攻击附带中毒，护心镜改变承伤方式。

## 六、敌人与波次

| 敌人 | 行为 | 作用 |
|---|---|---|
| 小妖 | 直线追击 | 基础杂兵 |
| 狐妖 | 高速追击 | 逼走位 |
| 蛇妖 | 保持距离、吐毒弹 | 逼接近或绕后 |
| 僵尸 | 高血低速 | 精英/肉盾 |
| 水魔兽（Boss） | 弹幕 + 召唤小妖 + 半血转阶段 | 终局考验 |

波次曲线（原型）：

- 0–30 秒：小妖为主，1–2 只/波，教走位；
- 30–90 秒：加入狐妖、蛇妖，密度上升；
- 90 秒后：僵尸、精英出现，场上维持 25–40 只；
- **2:00 Boss 登场**，小怪继续刷新，形成「边躲弹幕边清杂兵」。

正式版按章节延长到 15–25 分钟，Boss 在章末。

## 七、完整单局结构（正式版）

| 章节 | 场景 | 时长 | 章末 Boss |
|---|---|---|---|
| 一 | 余杭 → 仙灵岛 | 6–8 分钟 | 蛇妖男 / 狐妖女 |
| 二 | 苏州 → 白河村 → 京城 | 6–8 分钟 | 僵尸王 / 蝶妖彩依 |
| 三 | 蜀山 → 锁妖塔 → 南诏 | 8–10 分钟 | 镇狱明王 → 水魔兽 |

章节内插入 **3 个「机缘」节点**（类似 Hades 的门）：三选一——

- **客栈**：回血、升级一张术法；
- **集市**：用铜钱买法宝/删术法；
- **秘境**：限时挑战，奖励高品质法宝。

机缘节点让每局路线不同，也给玩家喘息。

---

## 八、元进度与难度

- **轮回点**：每局结算获得，永久解锁新术法、新法宝、新角色。
- **记忆碎片**：解锁剧情图鉴，指向真结局。
- **十劫**：每劫 3 个词条（草木皆兵、退无可退、孤星、情劫……），通关解锁下一劫。
- 角色：首版李逍遥；后续解锁赵灵儿（五灵/治疗）、林月如（剑/暴击）、阿奴（蛊/召唤）。

---

## 九、叙事与结局

- 玩家是「回魂仙梦」里的执梦人，借李逍遥之身重走宿命；死亡 = 梦醒，不是 Game Over。
- 三个结局：天命（原作）、逆命（集齐五灵珠 + 灵儿情缘 ≥80）、忘情（坏结局，二周目「魔劫」）。
- 动作肉鸽的叙事要「轻」：开局一段、Boss 前一句、结算一段；不要把文本塞进战斗。

## 十一、美术 / 音频 / UI

- 国风手绘 + 水墨竞技场；角色用「字 + 光晕」的符号化表现（原型已用），正式版换立绘/剪纸风。
- 术法特效要「一眼认出属性」：雷=折线、火=环、水=盾、毒=雾、剑=实体飞剑。
- HUD 只留：血/经验/境界、计时、术法图标、Boss 血条。**不要小地图、不要任务栏。**
- 音频：民乐 loop + 命中/暴击/升级/开箱四类音效；Boss 战换鼓点。

---

## 十二、IP 与风险

- 2025 年 3 月大宇已将《仙剑》IP 交接给中手游，**商业化需授权**；先做原创化 fallback，或同人非商业。
- 风险一：动作手感。移动、碰撞、受击反馈必须跟手，否则一切白搭。
- 风险二：数值通胀。术法一多就变成「满屏光效」，需要控制同屏弹幕与伤害数字。
- 风险三：内容消耗快。动作肉鸽通关一次只要 3 分钟，必须靠章节、词条、角色撑重复游玩。
