# 境界法相、术法赠礼与地形修正

本批保留孙小果原有衣饰，交付十四境九层的身体特效、每次大境界突破赠送三次术法升级，以及已开放六关的模块化近景地形。其余章节开放情况不变。

## 玩法与兼容

- 人物面板新增「术法赠礼」页。每次成功突破大境界增加三次升级权益，筑基零次、仙王累计三十九次；可以暂存，也可习得新术法。沿用六门槽位和每境术法上限。
- 每门术法分别记录永久等级与赠送等级，战斗读取合成后的实际等级。面板逐项预览飞剑、剑阵、范围及伤害等实际参数。安全时免费重分配赠送部分；普通升级和宝箱成长不能撤回。
- 新加入或重新加入的术法从完整冷却开始，调整不恢复生命、护盾、剑意或既有冷却。未释放的旧构筑施法取消，已经飞出的攻击保持原参数和同目标伤害预算。
- 总赠送权益由 `3×境界序号` 推导，成功突破、消耗材料及赠送权益属于同一份存档事务；失败、刷新和死亡不重复奖励。分配保存失败会回滚术法、分配与冷却。
- 继续使用 `xunsheng-save-v3`；旧档无赠送记录时，既有术法全部认作永久成长，自动补齐当前境界的未使用权益。主档、备份、旧档迁移和多窗口保护保留。

## 境界外观

十四境依次为灵脉、金丹核、灵婴、元神轮、虚空残影、合体双相、琉璃法身、雷冠、仙绶、星宿、五气、三花、道轮、王印。属于本游戏原创视觉语言，不作为传统修炼体系的断言。

一至九层依次补充核心、胸肩灵脉、双臂灵纹、外部构件、流光呼吸、剑手能量、腿部与步行拖影、外轮廓和完整共鸣。身体特效跟随同一套脚底锚点、朝向、受击和攻击位移；战斗与人物预览共享绘制入口。护盾耗尽不会移除境界表现。

## 地形与碰撞

原图分辨率不足且弯桥被宽直线四边形代替，是背景模糊和桥外行走的原因。现在六关用512像素材质绘制256世界单位地块，弯桥的两条边缘、桥面、护栏和导航共用样条几何。原有营地与奖励ID保持稳定。

移动、闪避、击退与冲撞检查完整运动路径；驿站和读档使用显式安全传送。旧档位于水面时，恢复到附近可走地面，远离原路时也会搜索最近路线而非直接送回入口。山石、石灯、牌楼、残柱、柳树和小庙是独立透明素材。查询参数 `?collision=1` 可查看桥边碰撞调试叠图。

## 验证

- 13组脚本检查共336项：包含原存档、章节继承、营地、首领、拾取、动作、六图连通与25项新增赠礼／桥面回归。
- 新增用例先复现截图水面可走，修复后通过；六关检查弯桥中心可走、外缘阻挡，长距离位移不能直接跨水到另一岸。
- 真实隔离Edge浏览器：1440×1000桌面、390×844手机布局；三次升级、重分配、刷新恢复、素材加载、无横向溢出和运行异常。
- 实际绘制并逐像素摘要检查十四境九层共126种状态均不同，输出总览便于人工对比；另留有桥面与碰撞叠图。检查图位于本地 `output/playwright/`，不发布到网站。
- 浏览器视口与无头渲染测量不能代替真实手机硬件性能或长时间真人试玩。本次不声称已验证真人通关时长。
- 合成战斗更新与绘制测量：24只约3.77毫秒／步，48只约6.99毫秒／步，均通过脚底地形检查；该测量不包含真实设备完整合成开销，不等同于设备帧率。
