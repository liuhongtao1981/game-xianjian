# 《仙剑·回魂》卡通美术设定 v0.1

> 目标：一眼可爱、一眼能认、暗场景里不糊。主角、妖怪、场景共用一套「纸感 + 粗描边」的国风卡通语言。

---

## 一、风格一句话

**国风纸片卡通**：米白纸底、暖墨粗线、平涂色块、一层软阴影；角色 2.5 头身，配角更矮更圆，Boss 更大更暗但只亮一处。

参考坐标：

- 造型：Q 版武侠 + 剪纸玩具感（不是日式赛璐璐，也不是纯水墨）
- 颜色：宣纸米白、青绿、朱砂、旧金，整体压暗以适配夜景
- 情绪：可爱 > 恐怖；妖怪要「想捏一下」，不是「想吐」

---

## 二、造型规则

| 项 | 规则 |
|---|---|
| 头身 | 主角 2.5 头身；小怪 1.5–2 头身；Boss 3 头身 |
| 头宽 | 约为肩宽 1.8 倍；头越大越可爱 |
| 描边 | 外轮廓 6px、内结构 4px，暖墨 `#2A2320`，不用纯黑 |
| 转角 | 全部圆角，禁止尖角（除非是角/牙/爪） |
| 阴影 | 只加一层 15% 暗部 + 一处高光，禁止复杂渐变 |
| 剪影 | 每个角色必须有 1 个剪影记忆点：马尾、叶耳、大尾、盘身、官帽、巨角 |
| 眼睛 | 占脸 1/3，双高光；主角圆瞳，妖怪竖瞳/方瞳 |

## 三、色彩

| 色 | 值 | 用途 |
|---|---|---|
| 夜墨 | `#07090B` | 场景底 |
| 描边墨 | `#2A2320` | 所有轮廓 |
| 宣纸 | `#F4EAD5` | 设定图底、主角衣服 |
| 青绿 | `#3E6B63` | 主角内衬、蛇妖 |
| 妖玉 | `#7FBFA8` | 小妖、毒系 |
| 朱砂 | `#C8503F` | 腰带、妖纹、灯笼 |
| 旧金 | `#D9B877` | 法宝、描边高光 |
| 狐火 | `#E0704F` | 狐妖、火系 |

原则：一屏最多 4 个高饱和色；大面积留给夜墨与青绿，朱砂只做点缀。

## 四、主角 · 李逍遥

- **身份**：少年剑客，近战 + 御剑。
- **头**：偏大的圆头，暖墨短发，右侧呆毛马尾 + 红发带；两撮翘起的鬓角。
- **脸**：琥珀色大眼、双高光；扬眉；嘴角一颗小虎牙的笑；腮红只用 45% 透明度。
- **衣**：月白短袍 + 靛蓝马甲 + 藏青腰带 + 深蓝裤 + 棕色短靴；腰间挂一只小酒葫芦。
- **道具**：背后长剑（银灰剑身、金护手、蓝穗），作为剪影的一部分。
- **表情包**：常态坏笑 / 战斗咬牙 / 受击眯眼 / 升级惊喜（4 个）。
- **动画**：待机 4 帧上下浮动 4px；跑步 6 帧；受击横向挤压 0.1s；死亡缩小 + 纸片飞散。

## 五、妖怪

### 小妖（杂兵）
圆滚滚的玉色小妖，叶子耳、独角和圆肚皮；大眼 + 两颗小虎牙。动作是弹跳前进，死亡炸成纸屑。

### 狐妖（高速）
橙色小狐，三条尾的意象（设定图画一条大尾保证剪影），白脸颊、红妖纹、小灯笼。眼睛略眯，显得狡猾但不凶。

### 蛇妖（远程）
青绿盘蛇，头顶一朵小花（反差萌），分叉信子；身体用一条 S 形粗线解决，盘身压成一个椭圆。远程吐毒弹时头部后仰。

### 僵尸（精英）
清代官帽 + 黄符纸 + 前伸的双手；皮肤灰绿，眼睛半睁（困）。跳跃移动，脚下带一小团纸灰。

### 水魔兽（Boss）
蓝紫大鲵/河童混合体：巨角、侧鳍、背刺、发光青眼、锯齿大嘴。身体压暗，只让眼睛与水波发光；半血后眼睛转红。

## 六、场景 · 山水画

- **画法**：水墨三层山（远淡、中实、近黑）+ 一轮月 + 雾带 + 水面倒影；山体用短皴线与晕染，不用硬边。
- **颜色**：天空 `#070F16 → #1E3B44`，山体 `#1B3742 / #17303A / #122B34`，水面 `#16323B → #061118`。
- **点缀**：亭台剪影、松树、灯笼、飘落花瓣。
- **可读性**：山水整体压暗 25%，角色与弹幕仍是画面里最亮的东西。

后续场景同规则：**每张图只允许一个视觉焦点**（月/瀑布/塔），其余全部退成墨色剪影。

## 六点五、术法表现

| 术法 | 画面语言 |
|---|---|
| 御剑术 | 飞剑 + 拖尾残影，命中溅火星 |
| 五雷咒 | 折线雷链：外发光 + 白色芯 + 落点闪 |
| 三昧真火 | 扩散火环 + 上飘火星 |
| 万剑诀 | 环绕飞剑，剑身带光 |
| 冰心诀 | 旋转冰晶弧 + 淡蓝护罩 |
| 蛊毒 | 地面毒瘴 + 气泡 |
| 酒神咒 | 冲击波 + 金色碎屑 |
| 观音咒 | 莲花光晕 + 治疗数字 |

原则：**每个术法一个形状 + 一个颜色**，同屏混战时也能分清是谁打的。

## 七、UI

- 底板：半透明夜墨 + 1px 暗金边 + 内高光。
- 字体：楷体；标题字距 4–10px。
- 血条：朱砂渐变；经验条：青蓝渐变；Boss 条：紫。
- 术法图标：单字（御/雷/火/剑/冰/蛊/酒/愈）+ 属性色描边 + 右下角等级。
- 按钮：旧金渐变胶囊，按下下沉 3px。

---

## 八、资产规格与落地

| 资产 | 规格 | 用途 |
|---|---|---|
| 设定图 `*.svg` | 512×512，带纸底圆盘 | 设定展示、宣传 |
| 游戏精灵 `sprites/*.svg` | 512×512，透明底 | 游戏内直接使用 |
| 场景 `bg-island.svg` | 1600×900 | 竞技场背景 |
| 游戏内尺寸 | 主角 56–72px；小怪 40–56px；精英 64px；Boss 180–240px | 按屏幕缩放 |

落地方式（原型已可用）：

1. SVG 直接 `drawImage` 进 Canvas（透明、矢量、无需打包）；
2. 正式版建议导出 2x PNG 图集，按 `idle/run/hit/death` 分帧；
3. 所有精灵共用同一描边宽度与色板，换角色只换剪影与配色。

---

## 九、Do / Don't

**Do**

- 先看剪影：把角色涂黑，仍能认出是谁。
- 眼睛永远比设定大一号。
- 妖怪加一个「无害」细节（花、灯笼、符纸），可爱度立刻上来。
- 场景里给角色留一块更暗的空地。

**Don't**

- 不要用纯黑描边、不要用真实比例、不要加超过两层的渐变。
- 不要给杂兵加复杂纹样——同屏 60 只时会糊成一片。
- 不要把血、断肢、恐怖元素画实；用纸屑、烟、光代替。
