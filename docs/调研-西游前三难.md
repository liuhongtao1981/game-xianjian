# 《西游记》前三难：原文依据与游戏改编边界

核验日期：2026-10-18。用途：为《剑仙孙小果·重走西游》前三关提供文本依据。本文只把古典小说原文视为情节依据；后半部分为本项目原创设计建议。

## 1. 前三难的准确名称与顺序

| 关序 | 原文难名 | 可提取的主题 |
| --- | --- | --- |
| 第一难 | 金蝉遭贬 | 被记录的罪名、被剥夺的身份 |
| 第二难 | 出胎几杀 | 新生受到威胁、保护与控制 |
| 第三难 | 满月抛江 | 绝境托付、救人与因果 |

依据是第九十九回的灾难簿，原文连续列出上述三项；寻亲报冤是第四难，双叉岭上是第七难，两界山头是第八难。因此不能把孙悟空出世、大闹天宫或两界山当作八十一难的前三难。[《西游记》第九十九回](https://zh.wikisource.org/wiki/西遊記/第099回)

同一回中，观音发现灾难簿只有八十难，命再生一难以成九九之数。这可以启发“历难由谁记账”的叙事问题；游戏里的隐秘机构与伪造难簿仍是原创设定，不是原文结论。[《西游记》第九十九回](https://zh.wikisource.org/wiki/西遊記/第099回)

## 2. 可以确认的情节素材

**金蝉遭贬。**第一百回由如来说明：唐僧前世是其第二弟子金蝉子，因没有听法并轻慢教法，被贬真灵、转生东土。原文此处没有描写一场金蝉大战，也没有名为“金蝉判官”的守关怪物。[《西游记》第一百回](https://zh.wikisource.org/wiki/西遊記/第100回)

**出胎几杀与满月抛江。**唐僧身世故事中，刘洪与李彪谋害陈光蕊，刘洪冒名赴任并控制殷温娇。她生子后得到南极星君示警，刘洪归来欲淹杀婴儿。母亲借机将孩子安置木板、系上血书，顺江托命；法明和尚在金山寺救起，取乳名江流。难簿名为“满月抛江”，身世段落的时间表述不宜强行补成精确三十天。[《西游记》附录《陈光蕊赴任逢灾　江流僧复仇报本》](https://zh.wikisource.org/wiki/西遊記/附錄)

这段身世故事存在版本与编排差异：本次读取的维基文库将其列为附录；中国哲学书电子化计划所用编排将该故事列为第九回。项目说明统一写“身世故事／附录”，不把各版本第九回混为一谈。[维基文库附录](https://zh.wikisource.org/wiki/西遊記/附錄)、[中国哲学书电子化计划《陈光蕊赴任逢灾　江流僧复讎报本》](https://ctext.org/xiyouji/ch9/zh)

## 3. 孙小果寻找大圣的原创改编方向

以下角色、地点变化、阴谋、对白、道具与机制均为本项目原创演义，不作为《西游记》原有情节介绍。

主线可以是：多年后，大圣行踪成谜。剑仙孙小果追查一页被削去姓名的历难簿，进入三段旧事留下的“劫痕”。每关找到一条线索，逐步发现有人通过替换历难记录，让凡人相信受苦就是必须缴纳的功德。孙小果寻找大圣，是为寻求打破这种循环的方法。结构以被压下的证词、表里不一的守关者、关后反转推进；采用原创人物动机与证据链，不复刻《黑神话：悟空》的独有剧情、对白、角色造型或关卡流程。

| 关卡演义 | 场景与主题 | 原创守关首领及玩法 | 留给主线的证据 |
| --- | --- | --- | --- |
| 第一难·金蝉遭贬 | 焚经残殿、断裂金像、倒悬经页。主题：罪名与真相由谁解释 | 司谴金蝉：铜金蝉甲与封口面具；以判印落区、钟波、破甲窗口教会走位与蓄势反击 | 被刮去末行的贬谪敕文，背面有大圣留下的剑痕提示 |
| 第二难·出胎几杀 | 雨夜江州旧衙、纸灯与封闭院墙。主题：冠冕下的人祸 | 血契假官·刘洪：从人形官袍转为墨血契身；锁链扇扫、假身与护印让玩家辨认真正攻击来源 | 母亲藏下的血书残页，显示“保护”命令同时也是监视命令 |
| 第三难·满月抛江 | 洪江月夜、漂木、金山寺远灯。主题：所谓天命是否容得下一次主动救人 | 缚舟夜叉：本项目虚构的拦江执行者；潮汐扇区、锚链横扫与浮木安全区形成空间压力 | 护送婴儿的旧木板与大圣救人记号，证明他曾违命改写一场灾难 |

原文洪江巡海夜叉曾帮助龙王救陈光蕊；本项目“缚舟夜叉”必须明确为另一名原创角色，避免把原本救人的夜叉误写成原著恶角。

建议每关采用“开场演义 → 战场目标 → 首领预告 → 守关战 → 关后证词”的闭环。主题信息由可跳过的短演义、战场视觉和首领行为共同表达。守关首领生命归零后才解锁下一关；计时仅记录成绩，不作为过关条件。玩家生命归零才失败。

## 4. 与战斗设计衔接的建议

- 第一关只引入一种需要识别的主预警：落印后爆发；首领暴露窗口稳定，让新玩家理解“躲开后输出”。
- 第二关加入真假来源与有限召唤，优先训练目标选择；假身只制造干扰，不无限叠加血量。
- 第三关用潮汐改变安全区域；先独立展示潮汐与锚扫，末阶段才组合，保留明确可达的安全位置。
- 大招可命名“问天一剑”：聚势、剑鸣、天隙、落剑、余波五段演出；效果应同时覆盖清杂、短暂安全和首领破势，伤害设上限，不能直接跳过首领阶段。首领阶段转换期间不计资源消耗，并给出清楚反馈。
- 难度应主要调节敌方伤害、预警时长、首领组合与资源容错，避免只倍增生命造成拖时。故事内容与通关规则在各难度一致。

上述机制数值需以实际代码中的伤害频率、玩家每秒输出和可避伤窗口再校准；这些建议不意味着已通过实机平衡验证。
