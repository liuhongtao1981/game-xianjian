每关有独立路线、四个区域、十八座三波营地、四处精英挑战、十四个探索点、四类妖众和一个首领。每关开场三幕、三份证词、通关揭示与下一关线索相连；终章留下号山焚誓残书。

炼虚三关已通关且境界达到合体后可进入第十六关，随后逐关解锁。只有合体三关全部通关后才显示对应域外大妖。旧存档保留人物、术法、材料、关卡进度及战斗检查点。

合体三关掉落七彩补天芝，对应突破大乘的材料。普通大妖独立 30% 掉落；域外大妖生命及伤害为普通版本两倍，每次胜利必得完整配方的一半材料：七彩补天芝 6、天地精华 24。三关基础修为合计 11,520，普通首领潜在掉落合计芝 12、精华 48。晋升仍由既有游戏内自动突破与境界特效处理。

首领全程可受伤，正确站位完成三拍可获得三倍伤害窗口，半血进入怒相。预警提前锁定，不追踪落点；暂停冻结招式，清除预警不会被认作破招。最短换位时间按基础移速 238、四种难度的真实移动输入检验。

新增三幅场景、一套地面纹理、十二件场景物件、十五种妖众与首领共六十个动作姿态。图片使用内置 image_gen 生成；提示词、源文件位置、排版修订记录保存于 [heti-art-generation.json](heti-art-generation.json)，成品位于 `prototype/assets/heti-*.webp` 与 `prototype/assets/actors-{twinforge,lotusname,mirrorwell}.webp`。图集仅进行格式转换与 UV 测量，保留源透明度。
