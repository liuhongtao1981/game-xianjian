# 九层修仙与六关发布

本批交付筑基、金丹共六关。十四境、四十二关目录已建立，其余三十六关未开放，不以重复地图占位。以下规则取代旧版三关说明。

- 每境一至九层，修为按九等分自动升层；九层圆满后才可消耗材料突破。升层生命与护盾最大值各加2%、伤害加1%，不补满护盾。突破失败不降层。
- 筑基地图6400×4600，金丹7200×5200；六张重制地形、四探索区域、每关十八处三波营地与四处精英。驿站周围营地清理后可在安全状态下返回。
- 桌面普通怪上限：故事36、标准48、困难56、极难64；触屏或窄屏最高24，保留所有波次预算。探索巡逻无限，首领战援军单独限制六只。
- 教学营地生命倍率1，初段1.8，中段4，后段6，另叠加章节、难度与精英倍率；不按停留时间增加生命。
- 金丹首领：压山石魁的锁柱只能诱锤破坏；无籍追猎将的幻印反击、实印可破，随后需避过三段追链；封喉白蛟需破鳞、诱冲岸，再连续迎过两重导雷潮的干岸缺口。
- 当前破境材料规则（2026-10-20更新）：对应关卡大妖30%概率掉落本篇核心材料，精英不再掉落核心。域外超级大妖生命与实际伤害均为同关同难度大妖的2倍，胜利100%获得核心与灵蕴各50%突破配方；连续两胜可备齐一份材料，修为独立积累。域外不推进主线；死亡、刷新不重发已领奖励，也不重抽落空结果。首次任务修为不重发。旧版定向材料待领奖励仍兼容。
- 术法上限为5＋大境界序号，保留六门术法及八件法宝。金丹六级、大乘十一级、太乙十六级开放三档形态；飞剑、剑阵分层参与真实命中，限制同目标重复伤害。
- 按C或点击“人物”，查看中央动态角色、两侧属性、八件法宝、术法和材料。手机可向下滚动查看属性。面板暂停战斗，预览动画独立运行。
- 主存档为`xunsheng-save-v3`，支持v2完整存档和v1入口构筑迁移，保留旧档及有效备份。旧人物属性不降低，旧营地完成记录和已领奖励保留。

## 本批验证

语法19项；遭遇14项；继承8项；自动存档24项；修仙22项；扩展15项；拾取25项；战斗61项，合计188项脚本检查。声音另有36项行为检查、85个媒体文件解码和100项来源哈希检查。

108处营地均能完成三波并在每图发放四份精英宝箱。导航网格验证六图营地、奖励和祭坛均与入口连通。覆盖旧档迁移、损坏回退、多窗口覆盖、未选卡、待领奖励、首领安全恢复与冷启动选金丹关卡。

一级主路脚本连续六关获胜，调强后约442至547秒一关；全探索脚本另一种子连续六关获胜，约457至575秒。见`expansion-mainroute.json`与`expansion-fullroute.json`。脚本读取完整预警并高效选卡，不能当作真人时长或通关率。真人主路25至35分钟、完整探索45至60分钟仍是待校准目标；本批不宣称已经验收达成。

真实Edge浏览器已检查桌面1440×1000与手机390×844：人物面板、滚动属性、地图、怪群、物品与首领素材加载，无运行异常及横向溢出。截图位于本地`output/playwright/`，不随网站发布。浏览器模拟视口不代表真实手机硬件帧率。
