# 仙剑题材肉鸽游戏 · 相关作品调研

> 调研目的：为「仙剑 + 肉鸽」立项做竞品与参考拆解。
> 结论先行：**这个组合已经被验证过两次**——同人圈有《仙剑98肉鸽版》，官方 IP 内有《仙剑奇侠传九野·谜域》；但两者都还是「在旧战斗上加一层随机关卡」，**没有一款把「仙剑的宿命叙事」真正做成肉鸽的循环内核**。这就是空位。

> **2026-10 方向修正**：项目改为**动作肉鸽**（控制主角、自动施法、升级提卡、宝箱出装备/术法），参照《灵画师》与幸存者类。本文的竞品拆解（尤其 98 肉鸽版、暖雪、哈迪斯）仍然适用；回合制/卡牌构筑部分只作为「提卡」系统的参考，不再作为主体。动作肉鸽的补充参考：暖雪（国产动作肉鸽手感）、吸血鬼幸存者（自动施法与密度）、哈迪斯（房间三选一与叙事循环）。

## 一、同 IP / 同题材：已经有人做过

### 1. 《仙剑奇侠传98肉鸽版》（同人 MOD，最直接的对标）

- 基于《仙剑奇侠传98柔情篇》改造的同人版本，作者持续更新，B 站可见 2.0 前瞻、2.62 实况，以及 3.0 的「落子无悔」新模式。
- 做法：保留原版回合制战斗与剧情骨架，叠加肉鸽层——随机路线、随机奖励、可叠加的难度词条（如「草木皆兵」「退无可退」），以及一局一结算的模式化玩法。
- 可借鉴：
  - **难度词条化**（把「更难的敌人/更少的回复」做成可勾选的「劫」），这是国内玩家最熟悉的肉鸽难度语言；
  - **一局 = 一段剧情切片**，用熟悉的地图节点唤起记忆；
  - 证明了「仙剑玩家愿意反复刷同一段剧情」。
- 不照搬：它依附原版素材与数值，战斗深度有限；且同人 MOD 无法商业化，说明**正式产品的位置是空的**。
- 参考：[V2.0 前瞻](https://www.bilibili.com/opus/1013357757811654697)、[2.62 困难实况](https://www.bilibili.com/video/BV1HpZhYrEVN/)、[3.0 落子无悔模式](https://www.bilibili.com/video/BV1mrjN6qEXF/)

### 2. 《仙剑奇侠传九野·谜域》（官方 IP 内的肉鸽模式）

- 《仙剑奇侠传九野》是软星/中手游体系的「推挤式 3D 角色扮演 CCG」，2021 年上线；其 PVE 玩法「谜域」是一套完整的肉鸽模式。
- 结构（据玩家攻略）：
  - **10 档难度**，逐档解锁，最高档有 240% 的货币增益；
  - 开局选**属性**（金/木/水/火/土）与**主将**；
  - **法器**（战斗内 buff，最多 5 件，可成套）＋**魂魄**（非战斗 buff），构成局内 build；
  - 路线节点：头目、宝库、机缘、商店、喽啰、营地，路线可规划；
  - 卡牌分白/蓝/紫/橙/红，单卡可升级 2 次（共 3 级），靠「多拿卡 + 不重复 + 高品质」计分；
  - 结算货币「谜尘」，局外买卡包，形成「PVE 养 PVP」的循环。
- 可借鉴：**法器成套**（套装效果驱动 build）、**路线收益梯度**（头目 > 宝库 > 机缘 > 商店 > 小怪）、**计分而非单纯通关**（延长重复游玩寿命）。
- 不照搬：它是卡牌 PVP 游戏的附属模式，节奏偏「每日打卡」，叙事几乎为零；「谜尘→卡包」的付费/养成结构不适合单机买断。
- 参考：[谜域速通攻略](https://www.7723.cn/strategy/70446.html)、[九野上线报道](https://m.ithome.com/html/537935.htm)

### 3. 同题材（修仙/国风）商业肉鸽

| 作品 | 类型 | 关键机制 | 对我们的意义 |
|---|---|---|---|
| 暖雪 Warm Snow | 动作肉鸽 | 飞剑、圣物、宗派/流派、词条堆叠 | 证明「国风 + 肉鸽」有大众市场；飞剑手感是仙侠动作化的标杆 |
| 修仙故事：无尽剑域 | 卡牌肉鸽 | **以「寿元」为代价**、剑之世界、极致打击感 | 「修仙资源 = 局内倒计时」的设计值得抄：寿元即压力 |
| 弈仙牌 | 修仙卡牌构筑（PVP 为主） | 境界晋升（炼气→筑基→…）、仙命、卡组连锁 | 修仙成长线可以做成「境界」而非「等级」 |
| 卡包修仙 | 抽卡 + 肉鸽卡牌（移动端） | 开卡包做 build、轻量循环 | 移动端「短局 + 开包」的可行性参考 |

## 二、品类标杆：必须拆的三款

### 4. 《杀戮尖塔》（Slay the Spire）

- 卡牌肉鸽的定义者：分支地图、可见敌人意图、遗物、卡牌升级、角色=职业。
- 关键启示：
  - **「一局 45 分钟、一屏信息可读完」**是这类游戏的黄金手感，仙剑的回合制底子天然适配；
  - 地图分支 = 玩家自己写故事，比线性剧情更适合反复游玩；
  - 遗物（法宝）要能**改变规则**，而不只是加数值。

### 5. 《哈迪斯》（Hades）

- 把「死亡」写进叙事：每次失败都推进人物关系与台词，玩家不觉得在「重开」，而在「继续」。
- 关键启示：**仙剑的「宿命/轮回」主题与肉鸽的死亡循环是同构的**——这是本项目最大的叙事杠杆，详见设定案。

### 6. 其他可参考的循环设计

- 《月圆之夜》：单机卡牌肉鸽的移动端范式，轻叙事 + 多职业。
- 《不思议迷宫》：迷宫探索 + 彩蛋事件，证明「事件文本」本身可以成为奖励。
- 《骰子地下城》：把随机性做成可看的「骰面」，降低肉鸽的不可控挫败。

## 三、空位判断

| 维度 | 现状 | 空位 |
|---|---|---|
| IP + 肉鸽 | 只有同人 MOD 与 PVP 游戏的附属 PVE 模式 | 没有一款**以叙事轮回为核心**的仙剑肉鸽 |
| 战斗形态 | 原版回合制（MOD）/ 卡牌 CCG（九野）/ 动作（暖雪） | **回合制小队 + 卡牌构筑**的混合体尚无人做 |
| 情感体验 | 肉鸽普遍「机制驱动」，仙剑玩家要的是「意难平」 | 让「改写结局」成为可玩的终极目标 |
| 商业化 | 同人免费、九野免费+内购 | 单机买断（Steam）+ 移动端移植 |

**风险**：
1. **IP 授权**：2025 年 3 月大宇已将《仙剑》IP 交接给中手游，商业化必须走授权；同人免费发布仍涉及角色/剧情/音乐的使用边界。
2. **同人 MOD 已占位**：98 肉鸽版的口碑会拿来比较，必须做出它做不到的东西（构筑深度 + 叙事轮回）。
3. **内容量陷阱**：肉鸽的重复游玩会把内容短板放大 10 倍，事件与卡池必须够。

## 四、给本项目的 7 条设计启示

1. **难度做成「劫」**：10 档、每档 3 个词条，用「天劫/情劫/杀劫」命名，直接继承 98 肉鸽版的玩家语言。
2. **局内 build 三件套**：卡组（仙术/武技）+ 法宝（遗物，能改规则）+ 五灵珠（套装，决定终局）。
3. **路线收益要有梯度**：头目 > 秘境 > 机缘 > 商店 > 小怪，让「贪」成为决策。
4. **计分/评价体系**：除了通关，给「无伤」「不重复卡」「集齐五灵珠」等加分项，喂给高玩。
5. **死亡即叙事**：每次失败回到「回魂仙梦」，解锁一段记忆，而不是弹「Game Over」。
6. **短局**：目标 35–50 分钟一局、3 幕，适配直播与移动端。
7. **把「意难平」做成系统**：情缘值 + 隐藏事件 + 五灵珠 = 改写宿命的条件，让玩家为「另一个结局」反复轮回。
