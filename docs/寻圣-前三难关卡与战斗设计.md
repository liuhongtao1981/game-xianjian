# 《重走西游·寻圣》第一卷：被删去的姓名

2026-10-18追加：探索巡逻改为不限队数的每8秒补充，原地也生效，仍受桌面24/36/44/48、手机24的总量限制；营地与精英奖励不重复。跨关快照补齐当前护盾、剑意、术法/大招/闪避冷却与升级选卡计数，继续继承等级、经验、全部属性、术法和法宝，并兼容旧版存档。下方历史模拟时长若未注明为无限巡逻版本，仍属于有限巡逻版本，不代表本次节奏验收。

原典依据为《西游记》第九十九回的前三难：**金蝉遭贬 → 出胎几杀 → 满月抛江**。第二、三难属于唐僧身世；孙小果进入的是“劫痕旧事”。考据与直接文本链接见[调研-西游前三难](./调研-西游前三难.md)。

## 叙事总纲

“八十一难”仍在运行，灾难簿却开始删改受难者的名字。大圣失踪前拒绝在一张无主诏令上签字，留下指向旧事的金毫。孙小果追踪金毫，逐渐发现有人把救赎写成交易，把受难者的名字当作可以删改的账目。

故事以权力交易、失实证词、慈悲与利益冲突推进。隐秘账册、孙小果、三位守关者与失踪事件均为独立原创演义。角色的隐瞒来自各自目的；前三难不靠隐藏血统解决冲突，小果的重要性来自自己的行动。

## 第一难：金蝉遭贬 · 失声禅庭

### 场景与故事

旧灵山禅庭的断钟、焚毁祷旗与金色戒印留在灰黑石地上。小怪为缄言小僧、焚卷狻猊、诵律卷灵、镇钟金刚，分别对应戒律、焚卷与镇压。

监院声称金蝉因轻慢教法受贬。孙小果找到的残卷却记着：每一难，都须有人付命。监院愿提供大圣下落，条件是将最后三页证词投入戒火。小果选择拔剑。

### 守关：缄口监院

佩铁口罩、背残破光轮的黑金监院，拖着断钟。它是原创守账者。

| 项目 | 当前规则 |
|---|---|
| 标准基础生命 | 2400；再乘全局难度的首领生命倍率 |
| 护体 | 三枚缄言钟心存续时，本体不受伤害 |
| 机关耐久 | 首轮每枚基础130；受机关难度倍率和轮次成长影响 |
| 主动招式 | 镇音重锤追锁落点；钟身范围攻击与环形钟波；金刚踏庭锁向突进 |
| 开启破绽 | 先破三枚钟心，再躲过随后真实落下的镇音重锤并等待收招；诱导重锤砸钟也能破坏钟心 |
| 输出与循环 | 破钟只是前置步骤；有效避锤、收招完成后短暂暴露。破绽时间或额度耗尽后重结三钟，重新破钟和诱锤 |
| 失败后的处理 | 重锤有效命中玩家，或其预警被清除，均不开窗；必须再次完整完成诱锤、躲避与收势 |
| 怒相 | 血量过半后的下一次收势进入怒相，钟波加密、部分攻击范围扩大 |
| 教学重点 | 识别护体、转火机关、诱导落点、把大招留到可伤本体时 |

战后铁面落地，监院的嘴里没有舌头。证词中同一个收讫人的名字被金漆抹去。获得**被烧去的名册页**，纸背金毫指向江州。

## 第二难：出胎几杀 · 血诏陈府

### 场景与故事

雨夜陈府，红绸如封条，湿石院落倒映红灯。伪诏刀役、赤绸诏魇、报命朱吏、断籍禁卫体现血诏与行刑主题。

陈府每夜传出婴哭，天亮族谱便少一个名字。血诏声称为免江州受劫，须除掉襁褓中的孩子。孙小果发现落款与第一难账册出于同一只手；侍女留下空襁褓，要求他去问“谁在替天杀人”。

### 守关：血诏司命

黑铁面具、红诏缠甲、断齿行刑刀。它是冒用天命的原创执行者。

| 项目 | 当前规则 |
|---|---|
| 标准基础生命 | 3600 |
| 护体 | 两枚续命血诏形成护体，本体免伤 |
| 机关耐久 | 首轮每枚基础180；受机关难度倍率和轮次成长影响 |
| 主动招式 | 锁向断籍横斩、追身血诏落印；怒相追加延迟落印 |
| 开启破绽 | 先斩断两枚血诏，再完整避开两段锁向问斩；待两段招式结算、收刀结束后暴露 |
| 问斩结构 | 第二段比第一段延迟0.6秒，方向偏转；方向在预备时锁定，可侧移或闪避 |
| 失败后的处理 | 被有效命中，或用清场效果移除了尚未结算的问斩，都不会获得破绽；之后重试问斩 |
| 教学重点 | 机关破坏只是前置步骤，必须读完完整连招；在收势窗口集中输出 |

战后面具内挂着空白官印。获得**无主血诏**，刮掉的批注记着“大圣曾拒签此令，去向封存于江底”。第一难涂名与第二难无主诏形成证据链。

## 第三难：满月抛江 · 夜渡洪江

### 场景与故事

月夜洪江，湿石码头、栈桥、乌篷船和莲灯围绕连通陆地。深青水色与银白反光衬出孤灯暖黄。妖众为沉灯水鬼、逐浪獠妖、逆鳞江妖、缚舟锚尸。

永不腐烂的木板保存着互相覆盖的血书。河伯声称守护江流儿旧事，却用没有入册的死者点灯。它愿交出大圣消息，代价是留下孙小果的名字。

### 守关：沉灯河伯

角生白骨、胸悬莲灯的江妖，拖着封名锁。它是原创守账者，与原典救过陈光蕊的洪江巡海夜叉身份不同。

| 项目 | 当前规则 |
|---|---|
| 标准基础生命 | 5200 |
| 护体 | 两盏锁魂河灯存续时本体免伤 |
| 机关耐久 | 首轮每盏基础220；受机关难度倍率和轮次成长影响 |
| 主动招式 | 回澜枪突进、沉灯追魂落点与魂灯弹幕 |
| 开启破绽 | 先灭两盏河灯，再连续两次站进洪潮带内的青色安全缺口，潮势收尽后显露逆鳞 |
| 双重洪潮 | 两重冲击相隔0.8秒；缺口宽度依故事/标准/困难/极难为190/160/144/130世界单位 |
| 有效反制 | 必须在两次结算时都位于潮带及缺口内；逃离整条潮带或清掉预警不算完成 |
| 教学重点 | 连续空间判断与站位承诺，寻找安全缺口而非一味远离首领 |

战后灯芯里传出大圣的冷笑，**逆流金毫**逆水指向五行山。第一卷获得继续追踪的路，尚未找到大圣本人。

## 共通首领状态与输出规则

首领依次经历护体追击、预备锁向、出手、收势、破绽。普通攻击、大招、暴击与持续伤害都经过同一护体与额度判断，不能靠最低伤害、毒或残留飞剑绕过护体。

破绽期本体受到3倍伤害，但输出受本轮额度限制；额度耗尽即结束有效输出，未用尽额度的窗口也会按时关闭。首领重结机关后，必须重新完成本关条件。机关每轮基础生命增加5.5%（按首轮基础值线性累计），同时应用所选难度的机关耐久倍率。

| 首领机制参数 | 寻路·故事 | 行者·标准 | 劫火·困难 | 无间·极难 |
|---|---:|---:|---:|---:|
| 破绽时长 | 6.4秒 | 5.6秒 | 5.0秒 | 4.6秒 |
| 每次最大生命伤害额度 | 30% | 24% | 22% | 20% |
| 理论最少成功破招次数 | 4 | 5 | 5 | 5 |
| 机关耐久倍率 | 0.82 | 1.00 | 1.12 | 1.22 |
| 首领节奏时长倍率 | 1.13 | 1.00 | 0.93 | 0.87 |

“最少次数”假设每次都打满额度；实际构筑与走位不足会需要更多轮。**标准档无论单次攻击伤害多高，四个完美窗口都不能击杀满血首领。**这项机制约束已测试，但不等于整场难度已经完成真人平衡校准。

HUD显示剩余机关、当前反制提示、破绽倒计时和本轮伤害使用量；破绽伴随角色语音与特效。旧攻击使用独立令牌登记，过期招式不能替新一轮完成条件；清除预警会重试对应机制，避免误开破绽或永久卡死。

## 三种大招

每次出征携带一种大招，开局剑意100，施放消耗100。标准自然恢复每秒2，普通命中+0.2、普通击杀+2、精英击杀+8。大招及残留不返还剑意；满剑意与最低冷却必须同时满足。

| 项目 | 破戒·天剑归一 | 护生·莲华剑界 | 逆命·断流十八剑 |
|---|---|---|---|
| 定位 | 爆发、清弹、破机关 | 近身续航与防护 | 定向多段穿透 |
| 起手 | 0.9秒 | 0.6秒 | 0.45秒 |
| 表现 | 聚剑、巨剑落阵、径向剑气 | 剑莲、护盾与绿色剑界 | 三轮十八剑、定向剑流 |
| 基础伤害 | 300＋境界×22 | 150＋境界×16；剑界每秒25 | 每剑24＋境界×3 |
| 范围 | 施放点周围760世界单位 | 爆发半径250、剑界半径150 | 定向扇形，每剑最多穿透三个目标 |
| 防守收益 | 范围清弹与清预警、1.4秒无敌 | 回24%最大生命、增加40护盾、近身清弹、0.9秒无敌 | 切开前方600范围内弹幕、0.75秒无敌 |
| 最低冷却 | 24秒 | 28秒 | 22秒 |
| 使用代价 | 起手较长，没有治疗 | 需要靠近，远处敌人不受爆发影响 | 可落空，没有回复，后续剑流期间不持续无敌 |

单次大招所有多段累计对首领最多造成25%最大生命伤害；该上限包括暴击和残留。首领护体与单轮破绽额度同时生效，因此标准档同一窗口仍最多扣24%。清掉重锤、双诏或洪潮预警可以用于自保，但不会替玩家完成相应破招条件。

全局难度与关卡劫压相乘；首领地面预警至少0.65秒。普通妖众使用独立攻击时序，近战预备默认0.46秒，按难度缩放后的动作预备底线为0.32秒，不能将首领预警底线误用到全部普通攻击。

压力来自攻击时序、锁向追击、机关和站位条件。后关继承玩家成长，仍须通过真人试玩验证构筑与机制的实际强弱关系，不能仅凭生命增长判断挑战已经合理。

## 逐关解锁、存档与恢复

1. 新存档只开放第一难。只有本关首领已经死亡、击杀标记成立且玩家仍存活，才进入胜利状态并记录通关。
2. 第一、二关胜利时，立即保存下一关入口构筑并开放下一难；无需先点击行粮奖励。刷新或返回菜单后，可直接选择已经由前关解锁的新关。
3. 行粮为伤害+10%、生命上限+20、术法冷却-8%三选一；选择后更新下一关入口构筑并继续。选关入场不会重复给行粮。
4. 术法、法宝、境界、当前经验、全部强化、毒伤被动、当前护盾、剑意与剩余技能冷却跨关继承，升级选卡计数也保留；下关生命至少恢复至70%，高于55%的剩余生命另回复15%上限，封顶满血。临时动作、无敌与场上投射物不带入新地图。
5. 死亡重试恢复本关入口构筑，该关尚未带出的强化不保留。已完成章节可重战，第一难始终可以重新开始。
6. 永久进度与后两关入口保存在浏览器 `xunsheng-progress-v1`。切换故事档与其他难度时调整40点基础生命差，再按入口生命比例及最低70%恢复。
7. 无效存档按校验结果回退到可用章节；重新开始第一难不会清空已获得的选关权限。
8. 没有生存计时胜利、时间到自动通关或时间上限失败。

## 主题妖众、动作与法术表现

三关各四种妖众，共12种独立角色；关卡主题行走图集共48帧。本轮新增五张动作图集、共72帧：三套妖众攻击图集覆盖12种妖怪各4帧，共48帧；一套首领攻击图集覆盖三位首领各4帧，共12帧；另一套首领独立行走图集覆盖三位首领各4帧，共12帧。攻击图集包含预备、出手、随势和恢复姿态。近战、突袭、远程、重击共享“预备—出手—收势”结构，各自的攻击距离、方向、动作长度和特效不同。

| 关卡 | 远程表现 | 近身与突袭表现 | 首领表现 |
|---|---|---|---|
| 禅庭 | 金色戒珠 | 戒火扑卷、镇钟重击 | 钟纹、金链、钟心破裂与重锤 |
| 陈府 | 三枚血诏扇面 | 赤绸锁向突袭、断籍刀斩 | 红诏悬令、双斩刀痕、收刀暴露 |
| 洪江 | 双枚魂灯 | 裂浪突进、沉锚重击 | 追魂灯、双重洪潮、逆鳞破绽 |

普通攻击在对应出手时刻结算；一次挥击只造成一次伤害。远程单位预备时锁向，释放帧才发弹；突袭在预备期间不前冲，冲刺过程使用路径碰撞，侧移能够躲开。重击不留下与动作脱节的独立延迟伤害区。

行走帧按移动距离推进，静止或蓄力时固定足底。主角普通施法使用单动作队列，御剑与法术分别获得约0.14秒、0.22秒独立起手，再按顺序释放；后续法术不能覆盖当前出手姿态。释放瞬间重新对齐实际目标、朝向和出手帧；大招优先，期间普通施法等候，恢复后重新建立预备动作。重试清除待释放招式。首领也使用预备、出手、收势与暴露状态。暂停会冻结世界动作和战斗特效。

画面采用Canvas 2D绘制、多帧图集、程序光效与动作状态机。当前没有真实3D骨骼、动作捕捉或布料物理；动作时序验证不代表这些能力已经实现，也不等于所有姿态都达到真人动作的自然度。

## 配乐、配音与字幕

三关各有行路与守关两个编曲，共6首原创合成器配乐。新语音包为32条中文神经男声MP3，覆盖法术、大招、剧情、首领登场与变相、破绽和预兆、分关胜利揭示及通用反馈。

说书人使用 `zh-CN-YunyangNeural`，孙小果使用 `zh-CN-YunxiNeural`，血诏司命使用 `zh-CN-YunjianNeural`；其余首领由语速、低音设置和轻量空间反射区分。原始音频由Edge神经TTS生成，成品保存在 `prototype/assets/audio/voice-v2/`，游戏运行仅播放本地文件。具体文本、来源、参数、哈希和后期处理以[声音设计](./寻圣-声音设计.md)及音频清单为准。

开场旁白对应剧情面板第一段，通关旁白对应本关揭示；字幕标出角色与当前准确台词。普通御剑不喊招，每关最多播放三种新法术的首次喊招，首领战停用普通自动喊招。破绽提示优先级最高，首领台词优先于大招；配音时背景音乐与音效自动降低。

这是通用神经合成声线，并非真人配音录制。旧23条录音仅作媒体错误时的兼容回退；新版语音的自然度仍需实际试听评估。
