# 重走西游 · 寻圣

当前开放筑基、金丹、元婴、化神、炼虚十五关，规划十四境四十二关，后续章节按境界制作并保持锁定。本批内容、美术来源与验证边界见[炼虚篇发布记录](../docs/炼虚篇-发布记录.json)，化神历史记录见[化神篇发布记录](../docs/化神篇-发布记录.json)，元婴历史记录见[元婴篇发布记录](../docs/元婴篇-发布记录.json)，成长基础规则见[九层修仙说明](../docs/九层修仙与六关发布.md)。旧三关文档保留作历史设计记录。

## 运行与操作

保留完整目录，从仓库根目录运行 `python -m http.server 4173 --directory prototype`，访问 http://localhost:4173/ 。WASD移动、空格闪避、Q/R/T三式大招、E交互、C人物、Tab舆图、F全屏；触屏使用左侧摇杆和右侧按钮。

选人页单击人物卡片选择同行剑仙，双击查看人物状态，也可按C查看已选人物。面板显示当前存档的境界、属性、术法、法宝和材料；无存档时显示初始状态。Esc、C或关闭按钮返回选人页，查看期间不续关、不结算成长、不写入存档。

术法获取：升级三选一采用不重复的加权抽取，每门未习得术法权重为4，已习术法精进和属性选项权重为1。普通宝箱在未满六门时有60%概率给予未习得术法；六门后不再提供新术法。已保存的待选卡牌和宝箱奖励保持原结果，刷新不能重抽。

舆图底部可选择巡营、精英、补给或大妖指引；箭头沿可走路线指示方向，不自动移动。章节筛选按境界显示，展开战况可查看详细劫压和破招说明。

## 探索与首领

筑基地图6400×4600，金丹至炼虚7200×5200，四连通区域、十八处三波营地、四处精英、三份证词、三份宝箱、三份补给及四座驿站。驿站清理周边后可安全返回。探索巡逻无限，普通怪同时存活上限为故事36、标准48、困难56、极难64，手机24。达到上限只延迟生成。

祭坛可自由挑战，不要求清空全图。入坛结束探索增援，首领全程可受伤，不设护体免伤、破绽伤害额度或大招对首领的25%限额；机关、诱招和收势破绽提供3倍伤害收益；玩家生命归零失败，只有击杀首领且自身存活才通关。关卡需前置通关及对应大境界才能进入。

首领开战3秒后开始召众，落地前有1.2秒预警。故事、标准、困难、极难每轮分别召唤24、36、48、64只小妖，桌面存活上限分别为48、72、96、128只，手机分别为24、36、48、64只。空间不足时等待完整一轮，不拆成零散补兵；破招期间暂停召唤，首领死亡清除召众。域外大妖使用相同难度规则。

## 长期成长与存档

每个大境界修炼一至九层，修为与完整材料达标后自动升层、破境，必定成功；首领战、人物面板、剧情和结算等当前内容均由独立破境演出暂停，演出结束返回原内容。暂停、死亡、卷首和卷首人物预览不触发成长，不再提供手动冒险突破。每次升层播放灵脉贯通特效；大境界突破持续5.2秒，天地法阵、冲天灵光与目标境界专属丹轮、灵婴、神轮、裂隙、双相、莲台、雷冠、仙羽、星轨、五气、三花、道轮、王印共同演出。危险预警附近装饰减淡，暂停冻结演出，读档不重复消耗或重播。破境核心改为对应关卡大妖30%概率掉落；对应境界全部三关通关后，卷首与通关页才显示域外挑战入口，超级大妖生命和实际伤害均为同关、同难度普通大妖的2倍。域外胜利100%获得本篇下一境突破所需核心材料和灵蕴精华各50%，连续胜利两次可备齐一份材料；修为仍须另行积累。域外不解锁主线，支持重战、死亡重试与刷新恢复；概率落空也会保存，刷新不能重抽。精英与满构筑宝箱只补灵蕴，旧档待领取的定向材料继续兼容。

战斗等级与修仙独立；术法只受当前大境界限制：筑基5级、金丹8级、元婴11级、化神14级，此后每次突破再开放3级；没有独立的18级或10柄飞剑硬上限，最多六门术法、八件法宝。突破开放上限，升级选卡投资后才获得更高等级及多轮、多层形态。御剑与万剑随等级增加飞剑，五雷每级增加一道落雷目标；其余术法逐级扩大范围，毒域与酒神也延长施法距离。冰心护域可驱散敌弹，观音在定点回春区域内分段治疗；赠礼面板显示实际数量和距离变化。未习得术法可点击“习得·1点”，确认后消耗1点并成为已习得Lv.1；后续每升一级再消耗1点，仍受六门携带上限约束。按C打开中央人物面板，查看属性、术法、法宝和天材。

每5秒及关键节点保存，退出和失焦补存。主档为 `xunsheng-save-v3`，保留v2和v1迁移、最近有效备份与多窗口冲突保护。刷新可恢复探索，首领战返回入坛前检查点重打；死亡保留成长，已领稀有奖励不因刷新或死亡重发。

跨境续关：每境第三关选择磨剑、养生或静心后，若尚未达到下一境，先记录行粮并返回本关探索；游戏内修为、材料达标后自动破境，完整演出结束自动进入下一关故事。材料不足显示具体缺口，去同境域外挑战仍保留所选行粮，胜利后可继续已选行程；行粮只在真正换关时生效一次。刷新保留待续行程。此流程修复了旧逻辑先检查下一境门槛、又禁止结算页突破，造成三项均无法继续的问题。尚有待选升级时先领取，当前开放篇章终章仍不进入未制作章节。

## 验证

Node.js运行 `tools/check-syntax.js`、`check-director.js`、`check-carryover.js`、`check-saves.js`、`check-cultivation.js`、`check-expansion.js`、`check-infant.js`、`check-pickups.js`、`check-combat.js`。音频完整检查为 `node tools/check-audio.js`，需要FFmpeg。桌面与手机截图检查为 `node tools/check-ui.js`，需要Playwright及Edge；可用PLAYWRIGHT_NODE_MODULES指定依赖目录。

原六关已从一级完成主路与全图脚本验证；本批元婴三关以声明的40级继承构筑完成连续探索与首领验证，数据见`docs/元婴篇-探索验证.json`。代理读取完整预警，不能代表真人通关率或时长。真人目标时长与真实手机性能仍需试玩校准。

万剑诀不再限制四圈：1/6/11/16/21级展开第1/2/3/4/5圈，此后每五级继续展开；新圈的起始剑数按 `5+i×(i+3)/2` 计算（i从0开始，即5、7、10、14、19…），两次展开之间每级为最外圈增加一柄。半径同样按圈序计算，不再读取固定四圈数组；同目标每0.45秒最多结算一次剑轮伤害。冷却缩减上限统一为80%，含普通术法、大招冷却与独立剑意恢复。可选择携带1至3式大招，分别使用Q/R/T或触屏按钮；每式独立保存冷却和剑意，可依次连用。大招基础伤害随连续境界进度乘1.28的对应次方，再乘面板伤害倍率。每次施放对每个非大妖战斗目标首次命中至少造成40%最大生命伤害；后续剑雨与持续伤害不重复触发保底，机关和大妖按原本伤害规则结算。

化神篇为血契高庄、福陵喜堂、黄风沙海：人券反印、借耙断绸、背风藏神三种独立首领仪式，首领始终可直接受伤，完成仪式提供3倍增伤。每关普通波次28/30/32，保留难度加减、无限巡逻与手机24上限。三关首领30%概率掉落虚空晶髓；域外每战保底4份虚空晶髓与16份灵蕴。三关首次基础奖励仍合计32份灵蕴精华与5120修为，精英补充灵蕴。原元婴终章旧存档可继续进入化神篇。新增六段原创离线配乐；新剧情与首领台词以字幕呈现，未冒用已有角色录音。

关卡菜单随屏幕宽度铺满排列，点击已解锁关卡播放分幕故事，支持自动播放、暂停与前后翻幕。十五关以删名账册为黑暗主线，每关开场承接上一关线索；观看预览不覆盖当前存档。

新增验证：`node tools/check-realm-loot.js`；浏览器验证：`node tools/check-realm-loot-ui.js`（复用项目Playwright与Edge环境）。

剧情按实际语音结束事件自动翻幕。所有剧情、前情衔接、两位主角文本与域外故事均采用同一套厚重男声录音，共100段，试听也使用同一旁白。暂停与切换窗口会保留当前位置；音频加载或播放失败时停留当前幕，可重试或手动翻幕，不自动改用其他声线。主动静音后才按阅读时间翻幕。验证：`node tools/check-heavy-voices.js`、`node tools/check-story-audio.js`、`node tools/check-story-audio-ui.js`。
